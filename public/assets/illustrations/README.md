Recommended illustration slots:

- `weirdmas-cover.webp` — optional welcome/dashboard cover art, landscape 3:2.
- `decoration-left.svg` and `decoration-right.svg` — wordmark decorations.
- `calendar-shape.svg` — background shape for each calendar day.
- `Book.svg` — icon for the empty sketchbook state.
- `empty-sketchbook.svg` — optional gallery empty-state illustration.

The welcome and dashboard currently use `cover.png` as the mascot artwork and the decoration SVGs beside the wordmark. `Book.svg` is shown in the gallery empty state. To use the recommended WebP filename, update its image source in `src/App.tsx`. `empty-sketchbook.svg` is not wired in yet.
